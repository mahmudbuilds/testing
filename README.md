## 🌿 Design Architecture (`taste-skill 2.5`)

- **Kind of Business**: Food Delivery Service & Hearth Provisions (`page-type="service"`, `site-kind="other"`).
- **Dealt Palette (`green-mat-chocolate` / Organic Linen)**:
  - Background: Warm natural linen stone (`#f8f5ee`)
  - Surface cards: Soft oat cream (`#ede7dc`) and ceramic white (`#ffffff`)
  - Ink: Roasted cocoa espresso (`#201713`)
  - Accent: Heritage sage green (`#2e6029`)
  - Primary Action / CTA: Warm terracotta orange (`#c64923`)
- **Dealt Typography**:
  - Headings / Display: **Fraunces** (soft variable optical serif display with vintage warmth).
  - Body / Interface: **Figtree** (geometric, approachable, human sans-serif).
  - Data / Timing: **Martian Mono** (precise courier times and metrics).
- **House Rules Enforced**:
  - **Rule 1**: Zero decorative captions under images; licence credits in a single footer line.
  - **Rule 2**: Every visual renders with rich photography; zero empty frames.
  - **Rule 3**: Hero fills the first screen alone with clear editorial hierarchy.
  - **Rule 4**: Equal left and right content edges via a unified `.wrap` container across all breakpoints (1440, 1024, 768, 390).
  - **Rule 5**: Micro-interactions: Cards lift 2px on hover, photographs zoom 1.025 within their frame, buttons step on hover and press on click.
  - **Rule 6**: Real editorial food photography leads every screen.
  - **Rule 9**: Real local districts only, zero fake coordinates or stock clichés.

## 🍽️ Key Features

1. **Daily Chef Supper Menu & Filter**:
   - Filterable categories: `All Items`, `Chef Suppers`, `Wood-Fired Hearth`, `Field & Garden`.
   - Real ingredient provenance (e.g. Willow Creek Grass-fed Angus, Sunstone Grain Mills, Oakwood Organic Farm).
   - Interactive `+ Add to Supper Box` button with tactile feedback.
2. **Interactive Supper Box & Slide-Over Drawer**:
   - Live cart tray counter in the header navigation.
   - Slide-over checkout drawer calculating dynamic subtotals.
   - Zero-waste returnable canister deposit protocol.
3. **The 3-Step Courier Logistics System**:
   - Dawn harvest from 12 regenerative valley farms.
   - Finished to order at 4 PM in cast iron.
   - Electric cargo trike dispatch with returnable insulated ceramic containers.
4. **Interactive Weekly Supper Box Planner**:
   - Dynamic household selector (1–2 Diners, 3–4 Family, 5+ Feast).
   - Frequency picker (3, 4, or 5 Evenings/week).
   - Real-time price-per-plate and weekly investment calculation.
5. **Grower Network Showcase**:
   - Detailed provenance breakdown with farm distances from the commissary kitchen.

## 📦 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/mahmudbuilds/testing.git
cd testing

# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
npm run preview
```
